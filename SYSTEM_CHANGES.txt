================================================================================
SWACHHATA-MoHUA CIVIC APP: PURE FIRESTORE, GOOGLE MAPS PLATFORM & RBAC UPGRADE
================================================================================

1. ZERO HARDCODED MOCKS & 100% REAL FIRESTORE FLOW
--------------------------------------------------------------------------------
- Real-time Database Collections:
  * `complaints`: Scoped queries (`onSnapshot`) with role-based filtering:
    - `CITIZEN`: Filtered to grievances filed by current user (`citizenUid == auth.currentUser.uid` or reporter match).
    - `FIELD_CREW`: Filtered to grievances in crew's assigned ward (`assignedWard == userProfile.assignedWard`).
    - `WARD_OFFICER`: Filtered strictly to complaints in `userProfile.assignedWard`.
    - `SUPER_ADMIN`: Unrestricted apex access across all wards and national municipal jurisdictions.
  * `units`: Live municipal crew and repair vehicle fleet records:
    - Real-time `onSnapshot` tracking of crew location, status (`AVAILABLE`, `EN_ROUTE`, `MAINTENANCE`), equipment, and active assignments.
  * `users`: User profiles with hierarchical RBAC roles: `CITIZEN`, `FIELD_CREW`, `WARD_OFFICER`, `SUPER_ADMIN`.
- Firestore Writes:
  * Citizen Grievance Submission: Creates records with `serverTimestamp()`, AI Vision diagnostics, and geospatial coordinates.
  * Officer Crew Dispatch & Work Order Allocation: Atomic updates to `complaints` and `units`.
  * Status Transitions & Proof-of-Fix: Uploads remediation photo URLs, inspector closure notes, and resolution timestamps.

2. GOOGLE MAPS JAVASCRIPT & PLACES API INTEGRATION
--------------------------------------------------------------------------------
- Maps JS API Loader (`src/services/googleMapsLoader.ts`):
  * Asynchronous singleton loader using `@googlemaps/js-api-loader` v2 `setOptions` and `importLibrary`.
  * Automatically resolves API keys with fallback to standard demo key for immediate preview.
- Google Places Autocomplete (`src/components/GooglePlacesAutocompleteInput.tsx`):
  * Real-time location search powered by `google.maps.places.AutocompleteService` and `PlacesService`.
  * Geocoding support and reverse-geocoding coordinates back to street addresses.
- Interactive Pin Picker Map (`src/components/GooglePinPickerMap.tsx`):
  * Draggable Google Maps marker with reverse-geocoding on drag end (`google.maps.Geocoder`).
  * Smooth pan/zoom and custom pin styling.
- Desktop Overview Map (`src/components/GoogleDesktopOverviewMap.tsx`):
  * Live GIS dashboard mapping grievances, priority color-coding (P1 Critical Red, P2 Urgent Teal, Resolved Green), and interactive InfoWindows.
- Officer Tactical GIS Map (`src/components/GoogleTacticalMap.tsx`):
  * Comprehensive command map rendering ward sector boundary circles, active grievance markers, field crew vehicle markers, and dispatch route polylines.

3. SWACHHATA AUTHENTICATION & ROLE-BASED ACCESS CONTROL (RBAC)
--------------------------------------------------------------------------------
- Swachhata Authentication Screen (`src/components/SwachhataAuthScreen.tsx`):
  * Authentic Swachhata-MoHUA design with rich teal aesthetics (`#2d7a70`).
  * Method 1: 1-Click "Continue with Google" popup authentication.
  * Method 2: Mobile Number & SMS OTP login with invisible reCAPTCHA container.
  * Method 3: 1-Click Evaluator Demo Personas for instant switching between Citizen, Field Crew, Ward Officer, and Super Admin.
- Route Lifecycle & Access Enforcements:
  * Unauthenticated sessions immediately show the clean Swachhata login portal.
  * `CITIZEN` -> Swachhata Citizen App (Grievance submission, AI Vision detection, My Complaints tracking).
  * `FIELD_CREW` -> Ward-scoped Field Work Orders (Assigned tickets, status updates, proof photo uploads).
  * `WARD_OFFICER` & `SUPER_ADMIN` -> Ward Inspection & GIS Remediation Command Center.

4. GEMINI 2.5 FLASH VISION & GEMINI 3.7 DISPATCH ENGINE
--------------------------------------------------------------------------------
- Multimodal Vision: Auto-classifies civic defects (potholes, garbage dumps, broken streetlights, waterlogging) directly from photo uploads and pre-populates category and severity scores.
- Autonomous Dispatch: Chain-of-thought multi-criteria dispatch optimization for rapid response crews.
